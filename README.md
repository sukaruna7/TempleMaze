# Game Prototype: Temple Maze
  Date: 08/18/2024

## Gameplay
TempleMaze is a first-person game where you navigate through the temple and find the golden statue. 

## Learning Objectives
-  Pointers & references
-  Actor & scene components
-  Including header files
-  Lighting with lumen
-  Modular level design
-  Line tracing & collisions
-   While & for loops & arrays in C++ and calling C++ functions in Blueprint.
